# 🔐 Tela de Login | Login Page

Projeto de uma **tela de login moderna**, desenvolvida com HTML5 e CSS3, com foco na estilização da interface, organização dos elementos e prática dos fundamentos do desenvolvimento front-end.

## 📸 Sobre o projeto

A interface apresenta um formulário de login com campos de usuário e senha, opção para lembrar o acesso, link para recuperação de senha e opção de cadastro.

O projeto foi desenvolvido com o objetivo de praticar conceitos de estruturação HTML e estilização CSS, aprimorando minhas habilidades como desenvolvedor front-end iniciante.

## 🚀 Tecnologias utilizadas

- **HTML5:** estruturação da página e dos elementos do formulário.
- **CSS3:** estilização, posicionamento, cores, bordas, efeitos visuais e layout.
- **Google Fonts:** utilização da fonte Oswald.
- **Boxicons:** ícones para os campos de usuário e senha.

## ✨ Funcionalidades visuais

- Campo para usuário.
- Campo para senha.
- Opção "Lembrar-me".
- Link "Esqueci minha senha".
- Botão de entrada com efeito hover.
- Link para cadastro de uma nova conta.
- Interface com fundo personalizado e efeitos de transparência.

## 💻 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Certifique-se de que a imagem de fundo esteja na pasta `img`, conforme a estrutura indicada.
4. Abra o arquivo `index.html` no navegador.
